# Contributing

Bug fixes and improvements to the 2.x line are welcome.

- Keep `ox_lib` as a dependency, and don't add code that needs RSG v3.
- Test your change on a running server and say how you tested it.
- Keep each pull request to one change.
- Don't remove license files or author credits.
- Only add third-party code whose license allows redistribution, and add it to `NOTICE.md`.

By contributing, you agree that your work is released under the license of the resource you changed.
